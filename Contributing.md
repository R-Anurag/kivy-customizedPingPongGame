## How to Contribute

1. **Fork the repository**  
   Click the "Fork" button at the top-right of this repository.

2. **Clone your fork**  
   `git clone https://github.com/<your-username>/Pathfinding-Visualizer.git`  
   `cd Pathfinding-Visualizer`

3. **Create a new branch**  
   `git checkout -b feature/your-feature-name`

4. **Make your changes**  
   - Add features, fix bugs, or improve documentation.
   - Keep your changes isolated to the branch.

5. **Commit your changes**  
   `git add .`  
   `git commit -m "Add a clear, concise description of your changes"`

6. **Push your branch**  
   `git push origin feature/your-feature-name`

7. **Open a Pull Request (PR)**  
   Go to the original repository and click "New Pull Request".

## Reporting Issues

- Use the **Issues** tab to report bugs, errors, or request features.
- Provide clear steps to reproduce the issue and screenshots if possible.
- Label the issue appropriately (bug, enhancement, question, etc.).

---

## Submitting Pull Requests

- Make sure your PR has a **descriptive title** and **summary** of changes.
- PRs should pass existing tests (if applicable).
- Include screenshots or GIFs for visual changes (optional but helpful).
- Assign reviewers if requested.

---

## Coding Style

- Use **PEP8 style** for Python.
- Keep functions **modular** and **well-commented**.
- Maintain **consistent variable naming**.
- Use docstrings for functions explaining inputs and outputs.

---

## Running the Project

1. Install dependencies:  
   `pip install -r requirements.txt`

2. Run the visualizer:  
   `python main.py`
